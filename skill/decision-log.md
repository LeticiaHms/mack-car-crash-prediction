# Decision Log

## Purpose
Make project decisions auditable for the academic report.

## Record
- decision
- context
- evidence
- alternatives
- rationale
- consequence
- date/version

## Decision categories
- data source
- cleaning
- missing values
- feature removal/creation
- target definition
- train/test strategy
- class imbalance
- model choice
- metric choice
- architecture
- technology stack
- visualization
- deployment

## Rules
Never write "because it is better" without measurable or methodological justification.
