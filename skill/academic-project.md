# Academic Project Review

## Review chain
Problem → hypothesis → data → methodology → EDA → features → model → evaluation → conclusion.

## Checks
- Is the research question precise?
- Is the target operationally defined?
- Are features available at prediction time?
- Is class imbalance addressed?
- Is the evaluation protocol valid?
- Are conclusions limited to evidence?
- Are data limitations documented?
- Is reproducibility possible?

## Critical distinction
Observational accident data can reveal associations and predictive patterns. It does not by itself establish causality.

## Acceptance
The final project can explain:
1. What was predicted.
2. From which information.
3. How the model was trained.
4. How it was evaluated.
5. Which factors were associated with severity.
6. What the model cannot conclude.
