# Documentation

## Expected documents
- README.md
- ARCHITECTURE.md
- DATA_DICTIONARY.md
- EDA.md
- ML_METHODOLOGY.md
- MODEL_CARD.md

## Rules
Documentation must match the implemented code and datasets.

Always document:
- PRF data origin
- coverage period
- target definition
- feature definitions
- preprocessing
- train/test strategy
- metrics
- limitations
- reproducibility instructions

Do not fabricate results, dataset statistics, or model performance.

## Academic language
Prefer:
- "associated with"
- "predictive signal"
- "observed relationship"

Avoid unsupported:
- "causes"
- "proves"
- "guarantees"
